## MCP tools are passive

This is the most important thing to understand about how MyGist behaves, and it
surprises people:

<Callout type="warn">
**Nothing reads your messages in the background.** MCP tools run only when a
client calls them. MyGist does not observe your conversation, and it cannot
notice that you said something worth remembering unless the client asks it to
look.
</Callout>

So by default:

- the assistant **reads** your persona when you ask about yourself;
- the assistant **writes** to it when you explicitly ask;
- saying *"I started learning Rust"* mid-conversation changes nothing.

That is a deliberate limitation. A tool that silently recorded everything you
typed would be a different product, and a worse one to trust with this data.

## Turning on suggestions

If you want a conversation where things get noticed, say so at the start:

> For this conversation, call `suggest_persona_update` on my messages and tell me
> when something is worth saving.

Now the client passes what you say to `suggest_persona_update`, which returns
candidate updates. You still approve them — the tool proposes, it does not write.

## How suggestions are judged

`suggest_persona_update` weighs what kind of statement it is looking at:

| Kind | Example | Treatment |
|---|---|---|
| Declarative | "I am a developer" | High confidence |
| Insight or reflection | "This helped me understand pricing" | High confidence → learning log |
| Hypothetical | "Maybe I should try Rust" | Low confidence |
| Venting | "TypeScript is killing me" | Usually ignored, unless there is an insight in it |
| Question | "Should I learn Rust?" | Ignored unless it also states something |

Long messages are analysed sentence by sentence, so a paragraph of statements
ending in a question still yields the statements.

Confidence then decides what happens:

- **0.8 and above** — applied, and mentioned
- **0.5 to 0.8** — you are asked first
- **below 0.5** — dropped silently

### Insights go to the learning log

Conceptual and soft-skill learning is captured, not just technical facts —
"I realised titles don't guarantee commitment" counts. Entries get a topic
extracted from the surrounding conversation, a summary of what led to the
insight, and automatic tags.

### Duplicates are checked first

Every suggestion is compared against what you already have, through the search
index. If it matches something, the suggestion is rewritten from an `add` into
an update targeting that entry. Mentioning the same thing across five
conversations does not leave five copies.

## The honest limitation

Capture depends on the client actually calling the tool. Some clients do it
readily when asked, some forget after a few turns, and none do it unprompted.
If accuracy matters more than convenience, write the entry yourself — see
[Writing](/use/writing) — or use [the editor](/use/editor).
